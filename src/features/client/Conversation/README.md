# Conversation

- Rota: `/mensagens/:id`
- Acesso: cliente autenticado e sujeito aos guards da experiência.
- O que faz: apresenta o shell da área de cliente.
- O que não faz: não lê dados, não executa compras, mensagens, pagamentos ou cálculos nesta sessão.
- Dependências futuras: backend e integrações reais do domínio, a implementar no Superprompt 2.
