# Support

- Rota: `/admin/suporte`
- Acesso: equipa administrativa com MFA/AAL2 conforme o guard existente.
- O que faz: apresenta o shell da área administrativa.
- O que não faz: não executa operações administrativas nem consulta dados nesta sessão.
- Dependências futuras: RPCs, tabelas e Edge Functions reais a ligar no Superprompt 2.
