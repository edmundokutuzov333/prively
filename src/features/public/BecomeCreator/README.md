# BecomeCreator

- Rota: `/se-criadora`
- Acesso: público
- Papel: apresentar o percurso de entrada de uma futura criadora
- O que faz: apresenta o título, descrição e estado inicial da página.
- O que não faz: não lê dados, não submete formulários e não executa integrações nesta sessão.
- Dependências futuras: conteúdo legal ou fluxos reais a ligar no Superprompt 2, conforme o domínio.
